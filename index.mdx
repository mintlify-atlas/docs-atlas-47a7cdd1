Rust-GPU is a compiler backend and shader standard library that lets you write GPU shaders entirely in Rust. Instead of HLSL or GLSL, you write idiomatic Rust code — complete with Rust's type system, package manager, and tooling — and it compiles to SPIR-V for use with Vulkan, wgpu, WebGPU, and OpenCL.

## What is Rust-GPU?

Historically, GPU programming required HLSL or GLSL — languages that lack the rich module system, safety guarantees, and ecosystem of modern languages. Rust-GPU changes that by making Rust a viable target for GPU shader development.

The project consists of two main crates:

- **`spirv-std`** — A `no_std` shader standard library providing GPU-specific types (images, samplers, vectors) and SPIR-V intrinsics accessible from shader code.
- **`spirv-builder`** — A build-script helper that drives the `rustc_codegen_spirv` backend to compile Rust shader crates to `.spv` SPIR-V modules automatically during `cargo build`.

## Getting Started

<Steps>
  <Step title="Add spirv-builder to your build dependencies">
    Add `spirv-builder` as a build dependency and copy the `rust-toolchain.toml` from the rust-gpu repository to your project.
  </Step>
  <Step title="Write a build.rs">
    Use `SpirvBuilder` to compile your shader crate to SPIR-V as part of your normal Cargo build.
  </Step>
  <Step title="Write a shader crate">
    Create a `no_std` crate with `spirv-std`, declare entry points with `#[spirv(fragment)]` or `#[spirv(vertex)]`, and write your GPU logic in Rust.
  </Step>
  <Step title="Load and run">
    Include the compiled `.spv` binary in your application using `include_bytes!` and pass it to your graphics API of choice.
  </Step>
</Steps>

<Note>
  Rust-GPU requires a specific nightly Rust toolchain. Always copy the `rust-toolchain.toml` file from the rust-gpu repository to your project — the build will fail with a clear error message if the wrong toolchain is used.
</Note>
