Rust-GPU currently supports a limited set of platforms and graphics APIs. Because the project is still in active development and not yet distributing pre-built artifacts, support status is based on the current `main` branch. There are many possible hardware and driver configurations; this page documents what is currently supported, what is intended to be supported, and what is present but untested. Support for each item is divided into three tiers:

- **Primary** — Built and tested on CI.
- **Secondary** — Built but *not fully tested* on CI.
- **Tertiary** — Present in the codebase but not built or tested.

As the project stabilizes and CI coverage expands, more platforms and APIs will move up to higher support tiers.

## Operating System

| Operating System | Version | Support Tier | Notes |
|---|---|---|---|
| Windows | 10+ | Primary | |
| Linux | Ubuntu 18.04+ | Primary | |
| macOS | Catalina (10.15)+ | Secondary | Requires [MoltenVK] v1.1.2+ |
| Android | Tested on 10–11 | Secondary | |

<Note>
  macOS does not have native Vulkan support. Rust-GPU on macOS requires
  [MoltenVK](https://github.com/KhronosGroup/MoltenVK) **v1.1.2 or later**,
  which translates Vulkan calls to Metal. Ensure your MoltenVK installation is
  up to date before running Vulkan-based rust-gpu examples on macOS.
</Note>

[MoltenVK]: https://github.com/KhronosGroup/MoltenVK

## SPIR-V Targets

Pass one of these strings as the `target` argument to `SpirvBuilder::new` or as the `[build] target` value in `.cargo/config.toml`.

### Raw SPIR-V

```text
spirv-unknown-spv1.0
spirv-unknown-spv1.1
spirv-unknown-spv1.2
spirv-unknown-spv1.3
spirv-unknown-spv1.4
spirv-unknown-spv1.5
```

### Vulkan

```text
spirv-unknown-vulkan1.0
spirv-unknown-vulkan1.1
spirv-unknown-vulkan1.1spv1.4
spirv-unknown-vulkan1.2
```

### WebGPU

```text
spirv-unknown-webgpu0
```

### OpenGL

```text
spirv-unknown-opengl4.0
spirv-unknown-opengl4.1
spirv-unknown-opengl4.2
spirv-unknown-opengl4.3
spirv-unknown-opengl4.5
```

### OpenCL

<Warning>
  OpenCL target triples are present in the codebase but are **not supported** by
  `SpirvBuilder` or `rustc_codegen_spirv`. Passing any `spirv-unknown-opencl*`
  target to `SpirvBuilder::new` will return an error at build time. These
  entries are listed here for reference only.
</Warning>

```text
spirv-unknown-opencl1.2
spirv-unknown-opencl1.2embedded
spirv-unknown-opencl2.0
spirv-unknown-opencl2.0embedded
spirv-unknown-opencl2.1
spirv-unknown-opencl2.1embedded
spirv-unknown-opencl2.2
spirv-unknown-opencl2.2embedded
```

## GPU Requirements

Rust-GPU does not target specific GPU generations. Any GPU that supports **Vulkan 1.1 or later** with the latest officially released drivers should be able to compile and run the examples. You can verify your Vulkan version using the [`vulkaninfo`](https://vulkan.lunarg.com/doc/view/latest/windows/vulkaninfo.html) command from the Vulkan SDK:

```bash
vulkaninfo | grep "Vulkan Instance Version"
```

### Driver Downloads

Install the latest drivers for your GPU from the vendor's official source:

- **AMD** — [AMD Support](https://www.amd.com/en/support/kb/faq/gpu-56)
- **Intel (Linux)** — [Intel Linux Graphics](https://www.intel.com/content/www/us/en/support/articles/000005520/graphics.html)
- **Intel (macOS)** — [Intel macOS Graphics](https://www.intel.com/content/www/us/en/support/articles/000022440/graphics.html)
- **Intel (Windows)** — [Intel Windows Graphics](https://downloadcenter.intel.com/product/80939/Graphics)
- **Nvidia** — [Nvidia Driver Downloads](https://www.nvidia.com/Download/index.aspx?lang=en-us)
